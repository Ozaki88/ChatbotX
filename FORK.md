# Freya Sage fork of ChatbotX

This is Ozaki88's own copy of [ChatbotXIO/ChatbotX](https://github.com/ChatbotXIO/ChatbotX), based on the official release v1.17.1 (tag `upstream-v1.17.1`).

Every push to `main` builds the images `ghcr.io/ozaki88/chatbotx-*:main` (workflow "Build and Push Docker Images"). The Railway project `chatbotx` runs those images.

To take a newer official release: merge its tag from ChatbotXIO/ChatbotX into `main`.
